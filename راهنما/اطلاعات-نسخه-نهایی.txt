نسخه 1.1.0 پروژه بازی‌های متفکر
========================================

تاریخ به‌روزرسانی: 2026-08-23
محتوا: مأموریت هدیه تولد مادربزرگ + مأموریت راه نجات بلوط‌ها + گزارش مدیریت

ساخت نسخه قابل انتشار:

  npm ci
  npm run check
  npm run build

پس از اجرای موفق دستورها، محتوای پوشه dist باید روی هاست منتشر شود.

مسیرهای کنترل:

  /
  /?library=1
  /?play=1
  /?play=oak-rescue
  /admin

برای فعال‌بودن گزارش مدیریت، API و PostgreSQL را نیز طبق .env.example و docker-compose.yml اجرا کنید. راهنمای کامل انتشار آنلاین، HTTPS و بازگشت نسخه داخل PDF همین پوشه قرار دارد.
